Solana ID Perk Frame

The Perk Frame is a drop-in widget from the Solana ID Display Network (SDN). It detects the connected wallet and shows targeted perks the user is eligible for, based on their SOLID Score, tier, and badges.

Replace YOUR-AGENT-ID-HERE in the div class with the Agent ID you received during Solana ID partner onboarding.
